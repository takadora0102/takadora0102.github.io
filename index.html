制作プロジェクト

takadora-discord-bot運用中

DISCORD BOT / SYSTEM MONITORING

自宅サーバーの状態監視を担う自作Discordボット。Raspberry Pi 5のシステム状態を定期取得し、 スラッシュコマンドでの状態確認や、異常時のアラート通知を行います。

工夫点：常時稼働を前提にDockerで運用し、監視データはSQLiteに蓄積して履歴を追える構成にしました。監視間隔とアラート閾値を設定できるようにしています。
  • Python
  • Docker / Compose
  • SQLite
  • Raspberry Pi 5

自宅サーバー taka-rp5稼働中

HOME SERVER / LINUX

Raspberry Pi 5を常時稼働のヘッドレスLinuxサーバーとして構築・運用。 各種ボットや自動化ワークフローの実行基盤になっています。

工夫点：起動・保存メディアにNVMe SSD（Pimoroni NVMe Base）を採用し、速度と耐久性を確保。SSHによる管理と、Tailscaleによる安全なリモートアクセスを整えています。
  • Raspberry Pi 5
  • Linux (Debian系)
  • NVMe SSD
  • Docker
  • Tailscale

power-meter-hub開発中

MQTT / POWER MONITORING

MQTTブローカー（Eclipse Mosquitto）を中心に、電力まわりのデータを集約するための基盤です。 自宅サーバーのテレメトリ連携を見据えて開発しています。

工夫点：計測側と集約側をMQTTで疎結合にし、センサーやデバイスを追加しやすい構成を目指しています。
  • MQTT
  • Eclipse Mosquitto
  • Raspberry Pi 5

カスタムRaspberry Pi 5ケース設計中

CUSTOM ENCLOSURE / PCB DESIGN

Raspberry Pi 5専用のカスタムケースを設計中。ESP32によるファン制御や表示機能を一体化し、 専用PCBの設計まで含めて取り組んでいます。
